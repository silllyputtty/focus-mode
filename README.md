# Focus Mode

A native macOS menu bar focus timer for designers, makers, and anyone who works better with a deadline they set themselves.

> Commit to an outcome. Then start the clock.

[Landing page](https://silllyputtty.github.io/focus-mode) · [Download](https://github.com/silllyputtty/focus-mode/releases) · [Send feedback](https://docs.google.com/forms/d/e/1FAIpQLSfLZZatZ4KgezkacNFMsEipdeF4KRxKLsWfI6aboaQVMs13_Q/viewform)

## How it works

1. Open the app from your menu bar
2. Set a focus and an outcome
3. Choose a duration
4. Start the timer
5. Get a quiet completion notification when time's up

## Install

1. Download the latest `.zip` from [Releases](https://github.com/silllyputtty/focus-mode/releases)
2. Unzip it
3. Drag `FocusMode.app` to your Applications folder

**First launch:** right-click `FocusMode.app` → **Open** to bypass the macOS unsigned-developer warning. You only need to do this the first time.

## Requirements

macOS 14 (Sonoma) or later. Apple Silicon or Intel.

## Built with

- SwiftUI
- macOS `MenuBarExtra` API
- UserNotifications framework
